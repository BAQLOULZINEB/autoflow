AutoFlow — Vue déploiement

Trois façons de faire tourner le pilote, de la démo sur laptop au cloud gratuit.

Coût pour l'agence

  • • Laptop : 0 MAD, fonctionne hors ligne
  • • Cloud : offres gratuites Vercel + Render + Neon
  • • LLM : optionnel ; ~0,01 MAD par demande si activé

Déploiement

  • • frontend : vercel --prod (ou netlify deploy)
  • • backend : docker build / render.yaml
  • • docker compose up pour tout lancer localement

Sécurité pilote

  • • Token admin par en-tête, formulaire public sans token
  • • Téléphones masqués, données fictives
  • • Seul le texte du message part vers un LLM (si activé)

AutoFlow — Vue contexte

Qui parle au système, et la frontière clé : aucune sortie vers le client sans clic humain.

Frontière (FACT)

  • • Le système produit des brouillons ; une personne envoie
  • • Aucune disponibilité inventée : code déterministe
  • • Chaque décision est tracée avec acteur et raison

Humains dans la boucle

  • • Équipe : relit, modifie, envoie, complète
  • • Manager : remises, réclamations, longues durées
  • • Escalade = fonctionnalité, pas défaut

Hypothèses (pointillé)

  • • LLM optionnel — rules-only par défaut, coût 0
  • • n8n pour brancher WhatsApp / Typeform / Slack
  • • Aucun connecteur client réel dans le pilote
